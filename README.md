# Web File Commander

Minimal starter project for the "Web File Commander" application (BMAD Level 4 homework).

## Tech stack

- React + TypeScript + Vite
- Vitest for automated tests
- Plain CSS
- No backend

## Installation

```sh
npm install
```

## Development

```sh
npm run dev
```

Starts the Vite development server.

## Testing

```sh
npm run test
```

Runs the Vitest suite once.

## Check

Runs TypeScript validation (via `tsc` in the build), ESLint, the test suite, and the production build:

```sh
npm run check
```

## Project conventions

See [CLAUDE.md](CLAUDE.md).

## Roadmap

File-manager features (folder selection, folder trees, file lists, previews, access handling) will be designed and implemented later through BMAD. This starter intentionally contains none of them.
